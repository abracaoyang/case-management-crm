# 定聯 x 議題 x 案件｜紀錄管理系統

個人專用之客戶定聯、議題推進與案件追蹤紀錄管理工具。

> 註：『案件管理』專屬模組目前規劃於後續階段開發，現階段聚焦於「名單 × 議題」二維交匯矩陣與極速定聯微紀錄。

---

## 核心模組與操作

1. **定聯與議題矩陣**：
   - 橫向為各項專業與生活議題，縱向為客戶名單。
   - 儲存格記錄最近切入日期與推進狀態（預計提出、剛拋出、深談中、已完成、暫緩），滑鼠懸停可即時預覽最後一次溝通重點。
   - 左上角按鈕可隨時快速新增議題。

2. **三秒微紀錄抽屜**：
   - 點擊任一儲存格滑出紀錄面板，內建該議題之 UMBC 切入說帖備忘。
   - 快速記錄本次接觸管道、推進狀態與一句話回饋，存檔同步更新時間軸。

3. **議題庫維護**：
   - 自由新增、編輯或停用各類別議題（風險管控、投資理財、稅務傳承、生活議題、組織增員）與對應說帖。

4. **案件管理（後續開發）**：
   - 銜接深談與成交後的具體案件歷程、進度跟進與交付管線。

5. **Google Sheets 雲端雙向連動更新**：
   - 包含專屬後端程式碼 `code.gs`，可一鍵部署至 Google Apps Script Web App。
   - 支援將『名單 (Contacts)』、『議題 (Topics)』與『交匯歷程 (Touchpoints)』三張工作表即時同步更新至 Google 雲端試算表。
   - 系統更動自動在背景推送（Push），亦可在其他裝置隨時自雲端拉取（Pull）最新進度。
   - 完整 4 步驟設定教學請詳閱 [Google_Sheet_串接指南.md](Google_Sheet_串接指南.md)。

5. **資料安全與雙重防呆**：
   - 純原生 HTML5 + 現代 CSS + Vanilla ES6+，可直接雙擊 `index.html` 離線開啟使用。
   - 預設自動防呆儲存至瀏覽器 LocalStorage。
   - 內建一鍵 JSON 備份匯出與匯入功能，支援跨電腦無縫轉移。

## 快速上手指南

1. **直接開啟**：
   - 雙擊開啟 `index.html`，即可直接在任何主流瀏覽器中運行。
2. **快速搜尋議題與客戶**：
   - 預設聚焦於「議題」搜尋：鍵入「達文西」、「防癌」、「分紅」或「信託」，矩陣 X 軸即刻篩選出對應欄位，保留全名單以便橫向比對推進現況。
   - 亦可點選切換至「名單」或「全部」搜尋客戶姓名與標籤。
3. **進行一次微紀錄**：
   - 在名單「游長霖」與議題「身心停藥與防癌一次金」的交匯格子點擊一下。
   - 右側抽屜滑出後，查看上方內建的 UMBC 說帖，點擊「複製話術」發送給長霖。
   - 長霖回覆後，在表單記錄回饋與下次電話時段，點擊「儲存微紀錄」。
4. **維護與新增議題**：
   - 點擊頂部右上角「議題庫維護」，可新增如「外幣保單轉存」或「長照險理賠實例」等新話題。
5. **綁定 Google 試算表**：
   - 點擊頂部「雲端同步」，貼上您的 Apps Script Web App 網址並點選「測試連線」，即可享受全自動雲端背景連動。
